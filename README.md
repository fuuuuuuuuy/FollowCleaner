## 这是什么

FollowCleaner 是一个桌面端工具，帮助你把**微信（公众号 / 视频号）、哔哩哔哩、小红书**等平台的关注列表集中到一处，进行：

- **分类归档**：多级分类树 + 标签，给每一个关注对象安个"家"
- **多维筛选**：按平台、关注时间、互动频率、账号类型快速定位
- **批量操作**：批量选择、批量归类、批量导出
- **一键清理**：在分类视图中直接取消关注，支持批量取关 + 确认机制 + 回收站兜底
- **数据安全**：所有数据仅存储在本机，不上传任何服务器；开源可审计

## 为什么做它

各平台关注列表只增不减：几百上千个关注里，大量是"关注后再也没看过"的账号。但平台官方：

- 不提供跨平台的统一管理视图
- 不提供多级分类能力（B站/小红书仅有简单分组）
- 微信甚至没有关注列表导出入口，取关只能逐个手动操作

FollowCleaner 用"平台适配器（Platform Adapter）"架构把各平台差异收敛到统一数据模型，未来新增平台只需实现一个适配器接口。

## 架构概览

```
┌──────────────────────────────────────────────┐
│                前端（React + TS）              │
│  分类树 │ 账号列表 │ 详情面板 │ 批量工具栏     │
├──────────────────────────────────────────────┤
│              Tauri 壳（IPC / 自动更新）         │
├──────────────────────────────────────────────┤
│            Rust 核心（本地 SQLite）            │
│  ┌─────────────┬─────────────┬─────────────┐ │
│  │ WeChat      │ Bilibili    │ Xiaohongshu │ │  ← Platform Adapter 插件化
│  │ Adapter     │ Adapter     │ Adapter     │ │
│  └─────────────┴─────────────┴─────────────┘ │
│  数据获取分级：手动导入 ＞ 本地只读 ＞ 自动化    │
└──────────────────────────────────────────────┘
```

> 架构与技术决策详见 [docs/PRD.md](./docs/PRD.md) 与 [docs/backlog-roadmap.md](./docs/backlog-roadmap.md)。
