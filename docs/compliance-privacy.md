# FollowCleaner 合规与隐私说明

> 本文档是项目的合规底线文档，优先级高于一切功能需求。任何与本文档冲突的功能设计，以本文档为准。

## 1. 产品立场

FollowCleaner 是一个**开源、本地运行**的个人关注列表管理工具：

- 仅帮助用户管理**其本人账号**在各平台的关注关系
- 不提供、不鼓励任何用于他人账号的功能
- 与微信（腾讯）、哔哩哔哩、小红书等平台**无官方关联、未获授权或背书**
- 所有平台名称、商标归各自权利人所有，本项目仅在说明兼容关系时使用其名称

## 2. 数据获取方式的分级与合规边界

项目将数据获取能力按风险分为三级，**默认只启用最低风险方式**：

| 级别 | 方式 | 数据流向 | 风险 | 默认状态 | 合规要点 |
|------|------|----------|------|----------|----------|
| L1 | 手动导入（CSV/JSON） | 用户自行整理 → 本地读取 | 最低 | ✅ 默认启用 | 不触及任何平台系统，纯个人数据处理 |
| L2 | 网页/授权只读（B站、小红书等） | 平台网页端 → 本机内存/本地库 | 中 | 用户主动配置 | 使用用户本人会话只读访问；遵守平台访问频率；不绕过权限控制 |
| L3 | 本地数据库只读（微信） | 本机微信客户端数据库 → 只读解密 | 较高 | ❌ 默认关闭，高级模式显式开启 | 仅读取本机本人数据；不修改、不上传；开启前强制免责声明确认 |

**L3 微信适配器特别约束**：
1. 仅做**只读**访问，绝不写入或修改微信任何数据文件
2. 解密密钥仅在进程内存中使用，不写日志、不写磁盘、不外传
3. 适配失败（版本不支持等）必须优雅降级到 L1，不做任何绕过尝试
4. 该功能随 V1.1 发布前需完成独立合规评审（见第 6 节）

**取消关注（写操作）约束**：
- 仅在 L2 适配器支持时开放；L1 手动导入数据源下取关入口置灰
- 强制限速（默认 ≥3 秒随机间隔、分批暂停）与风控熔断（遇到验证码/安全验证立即暂停）
- 不提供、不计划任何"突破频率限制""绕过验证码"的能力

## 3. 隐私保护原则

1. **数据零外发**：账号数据（昵称、ID、头像、互动记录、分类）仅存储于用户本机；除用户主动发起的平台请求外，工具不向任何服务器发送账号数据。
2. **本地加密**：本地数据库采用 SQLCipher 加密；密钥由本机特征派生，可选用户自定义密码。
3. **最小化遥测**：匿名使用统计**默认关闭**，首次启动明确询问；仅采集聚合数字与枚举事件（见 [metrics.md](./metrics.md) 事件字典），不含任何账号标识或自由文本；不接入第三方追踪/广告 SDK。
4. **凭据安全**：平台会话/Cookie 等凭据仅存本机加密存储，绝不上传；卸载即清除。
5. **日志脱敏**：任何日志不得包含账号 ID、昵称、凭据、密钥。
6. **可删除**：用户可在设置中一键清空全部本地数据；回收站记录 30 天自动过期。
7. **开源可审计**：全部代码（含适配器）以 MIT 协议开放，网络行为可被抓包审计。

## 4. 用户协议要点（随软件分发）

用户使用本工具即需确认：

1. 仅用于管理**本人**账号的关注列表，不得用于他人账号或任何侵犯他人权益的用途
2. 理解 L2/L3 数据获取方式可能处于平台用户协议的灰色地带，**由此产生的账号风险（如风控、限制、封禁）由用户自行承担**
3. 理解自动化操作（如批量取关）可能触发平台安全机制，工具已内置限速与熔断，但不对平台侧结果作任何保证
4. 不得将本工具用于刷量、账号买卖、数据倒卖等任何违法或灰产用途
5. 本软件按"现状"提供，作者不对数据丢失、账号异常等承担责任（同时产品通过回收站/备份机制尽力降低风险）

## 5. 法律风险自评（中国大陆语境）

| 风险点 | 评估 | 缓解 |
|--------|------|------|
| 平台用户协议违约 | L2/L3 方式可能违反平台许可协议 | 分级授权、显著声明、非官方声明、用户自担风险 |
| 反规避技术措施（《著作权法》第49条） | 微信 DB 解密可能被主张为规避技术措施 | 主张"用户访问自己设备上自己数据"的合理使用；只读、不传播数据；法律评审后再发布 L3 |
| 个人信息保护（PIPL） | 处理的是用户本人的社交关系数据 | 全本地处理、无服务器端处理者角色、最小化、明示同意 |
| 不正当竞争 | 贬损/替代官方功能的宣传可能引发争议 | 客观描述功能、不使用平台商标做品牌、不干扰平台运行 |
| 平台投诉/DMCA | GitHub 仓库可能被投诉下架 | 准备 DMCA 反答辩材料；保留 Git 镜像；不使用平台商标命名 |
| 用户滥用连带责任 | 用户用于他人账号/灰产 | 协议明确禁止、技术上限制本地使用、不提供批量账号能力 |

**产品名称与商标**：产品名 FollowCleaner / 关注管家，不使用"微信""WeChat""B站""小红书"作为产品名或图标元素；文档中提及平台名仅为兼容性说明。

## 6. L3（微信适配器）发布前置条件（Gate）

微信适配器在满足以下全部条件前不得合并发布：

- [ ] 完成一次独立法律/合规评审（社区或专业人士书面意见）
- [ ] 高级模式授权流程：默认关闭 → 风险说明全文 → 用户勾选确认 → 操作可随时撤回
- [ ] 只读行为经代码审计确认（无任何写路径）
- [ ] 密钥不落盘、不入日志经测试验证
- [ ] 不支持版本的微信明确拒绝并降级，无绕过逻辑
- [ ] README 与 Release Notes 含显著风险提示

## 8. 数据主体权利与响应

- 用户对其本地数据享有完全控制权：导出（CSV/JSON）、备份、彻底删除均在产品内完成
- 项目不收集用户身份信息，无账号体系，因此无服务端数据删除请求场景
- 安全问题可通过 GitHub Security Advisories 私密报告，维护者承诺及时响应
