# FollowCleaner 需求池与版本规划（Backlog & Roadmap）

> 本文档是项目持续开发的主索引。新需求先进入"待评审池"，评审后排期；架构上所有平台能力以适配器插件形式扩展，为未来留出余地。

## 1. 版本路线图总览

| 版本 | 代号 | 定位 | 核心交付 | 预估周期 |
|------|------|------|----------|----------|
| **V0.1** | MVP「整理盒」 | 合规可用的手动整理工具 | 手动导入 + 分类树 + 筛选浏览 + 导出 | 3~4 周 |
| **V0.5** | 「接上 B 站」 | 第一个自动数据通道 | B站适配器（导入）+ 概览仪表盘 | 3 周 |
| **V1.0** | 「断舍离」 | 清理闭环 | 小红书适配器 + 批量取关（确认/限速/回收站/日志） | 4~5 周 |
| **V1.1** | 「聪明一点」 | 智能化与微信通道 | 微信适配器（高级模式）+ 智能分类建议 + 智能视图 + 标签增强 | 4~6 周 |
| **V1.x** | 稳定迭代 | 兼容性与体验 | 微信/B站/小红书版本跟进、性能、UX 打磨 | 持续 |
| **V2.0** | 「生态」 | 社区扩展与多端 | 第三方适配器插件机制、适配器市场、E2EE 云同步（探索） | 长期 |

> 说明：取关能力在 V1.0 才开放，先验证"整理"价值与数据模型稳定性；微信因合规/技术风险最高放到 V1.1 高级模式。

## 4. 版本内容详述

### V0.1 MVP「整理盒」

**目标**：不触碰任何平台自动化，纯本地工具即可交付"跨平台关注整理"价值，合规零风险上线。

- P0：R001 手动导入（含模板/校验/错误报告）
- P0：R002 数据底座（模型/加密/去重）
- P0：R003 分类树；R004 浏览筛选；R005 批量操作；R006 工作台框架
- P1：R028 CI/CD、R021 空状态引导
- 验收：可发布 GitHub Release；用户能用模板导入 1000+ 账号并完成分类/筛选/导出

### V0.5「接上 B 站」
- R007 B站适配器（import + interactionData）；R008 仪表盘；R022 互动频率计算；R027 自动更新
- 风险：网页端结构/接口变更 → 适配器降级到 Cookie 只读 + 手动导入兜底

### V1.0「断舍离」
- R009 小红书适配器；R010/R011/R012/R023 取关闭环；R013 日志；R017 备份
- 上线门槛（安全红线）：风控熔断、限速下限、倒计时确认、回收站四项全部通过测试

### V1.1「聪明一点」
- R014 微信适配器（**前置条件**：合规评审通过、免责声明法律审阅、高级模式授权流程）
- R015 标签；R016 智能建议/智能视图；R024 主体合并；R025 兼容矩阵

### V2.0「生态」
- R018 插件机制（签名、隔离、权限声明）；R019 E2EE 同步（独立合规评审）；R026 浏览器插件伴侣；R020 社区平台

## 5. 风险与依赖（跨版本）

| 风险/依赖 | 影响版本 | 应对 |
|-----------|----------|------|
| 平台改版导致适配器失效 | V0.5+ | 适配器独立版本号、兼容矩阵、自动更新、手动导入永远兜底 |
| 微信合规评审未通过 | V1.1 | 微信适配器可无限期延后，不影响其他平台主线 |
| 取关风控策略过激引发用户投诉 | V1.0+ | 限速参数保守起步、熔断优先、Issue 模板收集案例 |
| 维护人力单点 | 全版本 | 适配器开发文档化（`docs/adapters/`）、社区认领机制 |

## 6. 上线检查清单（每版本通用）

- [ ] 功能验收通过（按 PRD 验收标准逐条）
- [ ] 无任何账号数据外发请求（抓包验证）
- [ ] 性能达标（10k 账号列表 <100ms 交互）
- [ ] Windows/macOS 兼容矩阵通过
- [ ] 危险操作（取关/删除）三道防护测试通过
- [ ] 遥测默认关闭、首次启动询问流程验证
- [ ] 免责声明与平台版本兼容说明随 Release 发布
- [ ] Release Notes 含风险提示与升级路径
